# Citation

Every factual claim must be traceable:

```
CLAIM
  → EVIDENCE
    → SOURCE (organisation + URL)
```

## Required chain

- A claim without evidence is unsupported. Drop it or mark it as an uncertainty.
- Evidence without a source is not evidence. Drop it.
- A source that does not actually support the claim is a false attribution. Do not attach it.

## Never

- Invent sources, URLs, DOIs, or quotation marks around text you did not retrieve
- Attribute a claim to a source that does not contain it
- Copy a citation from memory
- Collapse all sources into a bibliography that is not linked to claims
- Mark a claim as verified yourself — that is the Fact Checker's job

## When assembling the research package

- Attach sources to the claim they support
- Keep Fact Checker verdicts and source lists verbatim
- If the Fact Checker contradicts a source, keep both the original evidence and the contradictory sources
- Uncertainties belong in `uncertainties`, not as quietly cited facts
